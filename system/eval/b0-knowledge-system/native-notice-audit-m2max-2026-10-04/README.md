# Native notice audit diagnostic evidence

2026-10-04. C1-05 preparation and FIX-12; official quality and licensing verdicts remain pending.

The fixed upstream source hashes, selected Darwin native inputs, collected notices, raw failures, signed verification and three-project mock installation reports are preserved here. `summary.json` defines the scope. `build-info-darwin.txt` predates the package rebuild; the actual preview build info is `package/modules.txt`. The raw upstream parser-header record with local=null/identical=false is an unpaired LICENSE fetch, not an observed byte mismatch. Solidity normalization fields are auxiliary; the direct identical fields are the evidence.

`public.pem` and the detached signature are temporary test credentials, not operational trust. No private key, executable, archive, database, or model is committed. Synthetic installation `.log` files are retained intentionally. Raw logs can contain trailing spaces and are hashed unchanged. The Git copy is evidence storage and does not promise private runtime file permissions.

`evidence-manifest.json` records SHA-256 and bytes for every retained artifact except itself. Source snapshots describe the tested implementation; later documentation edits do not retroactively alter the preview. Other native attribution coverage, human compatibility/adequacy, Linux current recipe, operational keys and final evaluation remain outstanding.
