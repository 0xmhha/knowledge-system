- 대신 사실상 같은 조건의 재시행이 되어, 같은 문항을 다시 풀어도 읽은 양이 2~3% 안에서 같고 정답도 같았다. 이 3개에서는 한 번 재기의 잡음이 작았다(다른 문항에는 확인하지 않았다).

- 모든 문항에서 빈 응답은 없었다. 명령은 허용 폴더 밖을 열지 않았다(문항 5의 `/etcdutil.go`는 상대 경로의 일부로, 트리 안이다).

## 2. 판정

사전 표의 "60% 이하인 문항이 3개 이상"에 해당하지 않는다(0.97, 0.99, 0.97, 0.63). "그 밖"의 행동에 따라 연구를 마감한다.

## 3. 쓸 수 있는 말

- 이 종류의 문항에서 에이전트는 그래프를 쓰지 않고도 같은 답을 낸다. 쓰게 하면 달라지는지는 재지 않았다.
- 영향 범위 문항 하나에서는 읽은 양이 줄었다. 한 문항, 한 번이라 일반화하지 않는다.
