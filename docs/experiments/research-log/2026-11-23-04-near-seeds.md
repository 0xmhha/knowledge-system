# 2026-11-23 연구일지 04: near 출발 심볼로 잰 상한

세션: second-brain-eval-kit에서 연 Claude 세션. 작업 6을 마쳤다.

## 정한 것

- near 출발 심볼은 Claude가 수정 diff와 수용한 라벨을 보고 골랐다. 문항마다 1~2개, 모두 18개다. 수용한 라벨의 core는
  하나도 넣지 않았다(파일을 만든 뒤 스크립트로 확인). 고른 이유는 심볼마다 `why`에 적었다.
- 실행 전에 커밋했다(`715d93dd`). 실행기는 `-seeds seeds-near.json`으로 이 파일을 읽는다.
- near 결과는 상한으로만 쓴다(DESIGN 3장). 결정 A 판정은 blind 결과로 이미 했다.

## 결과

원자료: `knowledge-data/agent-eval/runs/20261123-ks-715d93dd-oracle-seed-near`. 요약: [data/near-result.json](../oracle-seed-offline/data/near-result.json).

| 방식 | 후보 안의 core | 10위 안의 core |
|---|---|---|
| graph_uncapped | 9/20 | 8/20 |
| graph_default_caps | 8/20 | 8/20 |
| grep | 5/20 | 5/20 |

문항별 recall@10은 graph 3승(sym-70, sym-56, sym-75), grep 1승(sym-74), 무승부 7이다.

- **grep이 이긴 sym-74:** 출발 심볼이 상수(`txSlotSize`, `MaxInitCodeSize`)다. grep은 `txMaxSize = 4 * txSlotSize` 줄로
  정답에 닿았다(5위). graph 방식은 후보가 1개뿐이었다. 상수에서 출발하면 따라갈 정방향 간선이 거의 없다.
- **거리:** 양방향으로는 core 20개가 모두 3 hop 안이다(1 hop 9개). 정방향으로는 6개만 닿는다.

## blind와 견주면

| 출발 심볼 | graph 10위 안 | grep 10위 안 |
|---|---|---|
| blind (출발 심볼이 정답인 5개 포함) | 7/20 | 6/20 |
| near (출발 심볼이 정답인 것 없음) | 8/20 | 5/20 |

blind의 10위 안에는 출발 심볼 자신인 정답 5개가 0위로 들어 있다. 그것을 빼면 blind는 graph 2개, grep 1개다.
출발점이 정답 바로 옆이면 graph가 정답을 10위 안에 올리는 경우가 늘었다. 문항이 11개라서 큰 경향만 본다.
