### A1 bounded-search continuation (2026-10-01)

`sqlitevec.SearchDetailed` now records `complete|incomplete|cancelled`, a stable reason, the SQL candidate superset count, the number examined and—after exact scan—the true eligible count. The exact fallback has a default ceiling of 16,384 SQL candidates; a caller can lower it through `SearchOptions.MaxExactCandidates`.
