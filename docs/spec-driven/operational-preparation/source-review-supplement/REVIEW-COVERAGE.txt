목적

확인한 자료
- 실제 공개 패킷: review-drafts/public-inputs.json. 사본은 원본과 바이트 일치.
- 초기 후보 장부에는 SRC-026이 남아 있으나 실제 공개 패킷은 이미 SRC-027로 교체.
  새 교체/범위 승인이 아니며 기존 replacement 기록과 고정 원문을 재대조했다.
- 운영 원문 제안 10개, 모듈 표기 8개, 파일 9개. 모듈별 consensus/wbft·core/rawdb 각 2개,
  core/state·core/txpool·eth/downloader·miner·p2p·rpc 각 1개.
- 기존 AI rubric 45곳. 상태/guard와 자원/비용의 자료 위치 제안 각 10개.
  중복 분류를 허용하는 자료 연결이며 정확도·필수 결함 수·자원 보장 판정이 아니다.
- 같은 사례의 기존 외부 문맥 5개, 근거 19곳. 독립 리뷰 15개로 세지 않는다.
- 45쌍 비교: 같은 모듈 2쌍, 같은 파일 1쌍. 의미적 가족 독립성은 전부 미검토.
- lexical-coverage-v1 및 context-v1의 offline Git commit→tree→blob 증명 재사용.
  원문 revision 0bf2f4d1bfeb6605006d556957ef8c045d8f8ed8.
  기존 body·근거 span의 행/byte/hash·공개 excerpt·private/public identity를 대조했다.

명확히 남은 판단
- priority 10개 모두 needs_human_requirements_review. 사례별 요구사항·영향 질문을 작성했다.
- SRC-007의 slice 구성, SRC-031의 반복 요청, SRC-036의 constructor 선택도 자원 검토
  출발 위치일 뿐 입력 크기·deadline·할당 상한·소유권/해제 보장의 근거는 아니다.
- 필수 guard/상태/자원 항목의 완전한 정답, 실제 결함 여부, 영향/우선순위는 미확정.
- 모든 입력은 이미 공개 원문·비공개 AI 초안에 노출되었다. fresh holdout으로 세지 않는다.
- 독립 사례/gold 0개. typed 보고서·그림·state handoff·host 실행 영수증은 미수집.
- 위 증거의 미수집은 제품 기능 부재를 뜻하지 않는다. 이번 수용 패킷의 증거 공백이다.
- 담당자 '미정', F-01~F-08 pending, freeze null, execution_allowed false, 정식 수용 0/9 유지.
