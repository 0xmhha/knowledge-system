지원과 불확실성
51개 함수 모두 base status partial 및 isolated_type_info_partial 진단을 보존했다.
규칙 pass는 51개 모두 matched_bounded이고 이번 관측에 rule cap 중단은 없었다.
그러나 short circuit, range binding, closure, opaque call, alias/메모리/field,
비동기·defer·select 등의 진단과 미지원 범위를 지우지 않는다.
matched_bounded는 선언한 제한 안의 후보 pass 완료이며 전체 의미 분석 완료가 아니다.
포함 파일은 기존 census처럼 build tag/platform과 무관한 추적 non-test Go 원문이다.
생성 파일·함수 외부 initializer·외부 호출자/실행 경로는 이번 로컬 관측으로 포괄하지 않는다.
새 syntax walker는 closure 깊이·직접 assignment RHS·인자 위치를 기록하지만
import/callee/type resolution이나 graph canonical identity를 증명하지 않는다.
