# Anzeon authorized-account gas tip override

**Status:** verified · **Subsystem:** A6 (Fee Delegation & Anzeon Gas) · **Type:** B3

Under the Anzeon hardfork, AnzeonTipEnv overrides the effective gas
tip for transactions signed by authorised accounts. GetAnzeonTipCap
returns the transaction's own GasTipCap (the sender's chosen tip)
for authorised senders, and the block header's GasTip for everyone
else. Authorisation is read from StateAccount.Extra at the current
block's state root; AnzeonTipEnv caches the lookup per block to avoid
re-reading state on every transaction.

## Invariants
- AnzeonTipEnv is only consulted on chains where IsAnzeon returns true at the current block; pre-Anzeon blocks use the standard tip path.
- The cached state is invalidated when SetCurrentBlock observes a new block whose state root or header GasTip differs from the cache.

## Pitfalls
- Reusing a stale AnzeonTipEnv across a reorg can yield wrong authorisation answers: the consumer must call SetCurrentBlock on each new block before reading GetAnzeonTipCap.
