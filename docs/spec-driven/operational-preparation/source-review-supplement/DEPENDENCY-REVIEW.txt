모두 비공개 AI 검토 초안이다. 4개 함수는 30개 독립 수용 함수가 아니다.
완전한 edge gold·CFG/postdominator 결과·품질 점수·독립 승인은 산출하지 않았다.

실제 구현과의 매칭 제안 — 아직 동결하지 않음
현재 구현의 Source/Variable/Occurrence/DefUse/Edge 구조와 역할 분기를 원문으로 확인했다.
동일 project·commit·function hash, 선언 위치, occurrence byte/role 및 CFG node 위치를
맞추는 기준이 필요하다. 같은 행에 여러 이름·읽기/쓰기가 있으므로 행 번호만 쓰지 않는다.
data/address/reference/aggregate/unknown dependence와 certainty를 섞어 채점하지 않는다.

블록 포함 관계나 break/continue의 문법상 소유자를 control_dependence로 자동 변환하지 않는다.
정상 종료 postdominator 계산, 비종료 경로·예외·panic·비동기 호출의 경계는 별개다.
지원 제한이나 매칭 불가 항목은 unknown으로 남기며 자동 false edge로 만들지 않는다.
matching-contract.json은 제안일 뿐이며 baseline·매칭 동결·예산·gold manifest는 미정이다.

파일 단위 위치 검사는 외부 importer를 연결하지 않는다. 전체 프로젝트 타입 검사와 다르다.
