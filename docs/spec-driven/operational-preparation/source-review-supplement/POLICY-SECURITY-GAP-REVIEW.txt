수동/자동·typed/legacy·원본 출처
- 현재 정책/보안 resolver는 수동 YAML을 graph node/관계·typed AnnotationPayload로 저장한다.
  typed description/remediation/severity는 retained_operator_value다. legacy merged DocComment는
  설명으로 유지하되 수정힌트/severity를 추측해 복원하지 않는다.
- runtime은 원본 YAML source_sha256/source_line/version/reviewer/reviewed_at/approval을
  보존하지 않았으므로 unknown으로 반환하며 identity_trust는 not_authenticated다.
- 별도 자료의 실제 YAML bytes/hash, symbol의 indexed Go commit/blob SHA, annotation의
  metadata_sha256는 서로 다른 증거다. Go commit/graph 해시와 resolver의 StartLine1을
  원본 YAML 행/인증된 검토자·승인의 증명으로 사용하지 않는다.
- 위조된 설명·reviewer 필드·header를 포함했다고 인증된 주체가 생기지 않는다. 현재 리뷰어
  인증/서명 검증·프로젝트별 권한을 구현한 것으로 문서화하지 않는다.
- automatic_rules는 separate_opt_in_rule_candidates_not_executed다. policy_security는
  자동 탐지기를 실행하거나 manual 태그를 자동 후보에 섞지 않는다. rule_candidates와 LLM
  해석/수정 권고/취약점 수용은 별도 증거·판정이다.

입력·stale·비공개 경계와 조회 한계
- strict raw decoder는 중복/unknown/null·잘못된 타입/범위·복수 선택자·trailing 문서를 거부한다.

직접 peer ACL·위조 header·배포 계약
- HTTPPolicy의 remote off는 loopback만, remote on/default는 loopback+private/LAN/link-local,
  explicit CIDR 설정은 loopback+지정 네트워크를 허용한다. 실제 배포 설정/위협 범위는 미동결이다.
- middleware는 직접 peer RemoteAddr에서 IP를 읽어 backend 전에 거부하며 X-Forwarded-For를
  peer identity로 신뢰하지 않는다. 현재 정책은 허용 네트워크 범위이며 리뷰어 인증이나
  symbol/project별 authorization을 제공하지 않는다.
- 허용 proxy가 연결한 경우의 직접 peer와 사용자가 주장하는 identity를 구분해야 한다.
  listen/CIDR/IPv4·IPv6/public/invalid/nil·forwarded spoof/proxy topology·기대 허용/거부와
  backend 미호출의 실제 배포 listener/소비자 영수증은 미확보다.
- readOnlyHint는 권한·검토자 인증이 아니다. stdio의 단일 subprocess 경로와 실제 HTTP
  listener·CIDR 경계를 동일한 검증 분모로 합산하지 않는다.
