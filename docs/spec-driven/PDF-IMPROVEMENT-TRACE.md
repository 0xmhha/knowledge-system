## 선택적 연구 항목과 범위 경계

초기 제안서의 다음 항목은 **누락된 필수 요구사항이 아니라 조건부 실험**이다. 필요성과 수용 기준이 입증되면 새 요구사항 번호를 발급하고 WBS에 추가한다.

- 전체 저장소의 전역 요약 질문에 대한 GraphRAG 커뮤니티 클러스터링: 국소 코드 위치 검색의 기본 경로로 채택하지 않았다.
- 긴 함수 청크의 겹침 조정: 경계 누락과 중복/비용을 측정한 뒤 결정한다.
- 여러 물리 벡터 컬렉션으로 분할: 실제 접근 패턴·부하가 요구할 때 결정한다.
- RDF·OWL·SHACL 스택: 상호운용성 또는 복잡한 추론 요구가 확인되면 평가한다.

이 표의 `구조 통과`는 mock/fake 서버 및 결정적 fixture의 정확성만 뜻한다. B/C의 실제 Ollama 평가와 그 결과를 반영한 수정이 끝나기 전에는 자연어 품질이나 출시 적합성을 `완료`로 표시하지 않는다.
