# N11 중요군 표본 부족 시 사전 규칙

2026-10-09 · **사용자 직접 결정 기록 / N11 전체 미완료**. 전체8/18, 요청5/15, 남은10개.

## 결정

질문: 중요군별 승인 독립 FINAL이 10개에 못 미치면 어떻게 처리할지. 결과를 보기 전에 정하는 규칙이다. 사용자 답: **“부족 군은 inconclusive 사전 고정 (권장)”**. 결정자 이름은 아직 입력되지 않아 null이다. [결정 기록](../../system/eval/b0-knowledge-system/refactoring-n11-shortfall-rule-2026-10-09/decision.json).

새 FINAL을 보내기 전에, 승인된 독립 군이 10개 미만인 중요군(CODE/WHY/POLICY/TRACE/ABS)은 descriptive/inconclusive로 고정한다. 그 군은 기본 활성이나 출시 근거가 될 수 없다. 10개에 이른 군만 기존 임계치로 판정한다. 나중에 군을 늘리려면 결과를 보기 전에 새로 검토해야 한다. 이 규칙은 기존 초안 protocol의 `small_group_policy`와 같은 내용이며, protocol 파일 바이트와 10개 기준·임계치·승인 입력5·이전 FINAL 제외는 바꾸지 않았다.

## 결정이 바꾸는 것과 바꾸지 않는 것

N11 완료는 이제 군별 10개 확보를 기다리지 않는다. 그러나 실제로 사용할 군의 gold·독립성·오염·ABS 근거에 대한 사람 판정, protocol·source·model·runtime 동결, 증거 결합은 여전히 필요하다. 이 결정은 그런 승인이나 동결이 아니다.

현재 제안 군은 CODE4·WHY4·POLICY1·TRACE2·ABS1이고 승인은 모두 0이다. 지금 상태로 평가하면 모든 중요군이 inconclusive가 된다. 그러면 N08/09/10의 품질 판정은 N18에서 기본 활성을 뒷받침하지 못한다. 기본 활성까지 가려면 일부 군이라도 10개를 채우는 보강이 따로 필요하다.
