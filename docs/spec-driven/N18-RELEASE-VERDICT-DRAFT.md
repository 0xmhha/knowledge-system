# N18 기본값·출시 판정

2026-10-11 · **사용자 승인, N18 완료**. 2026-10-12 현재 전체 17/18 완료이며 N16은 사용자 결정으로 보류(미충족) 중이다.

2026-10-12 후속: 사용자가 `feat/refactoring-followup`을 PR로 만들어 `main`에 squash merge하도록 명시 지시했고, PR #98이 `067ed5f3`으로 머지됐다. 10월 11일의 `main` 머지 보류만 해제됐다. 선택 기능 기본값, N16 보류, 독립적인 사람의 항목별 내용 검토 부재, 공개 배포·태그 보류는 바뀌지 않는다.

승인 기록: 2026-10-11 사용자가 2절·3절 판정을 "초안대로 승인"했고, N16은 "미충족으로 둠"을 골랐다. 당시 승인만으로는 머지·공개 배포 권한이 생기지 않았으며, 머지는 10월 12일 별도 지시로 실행됐다.

## 1. 무엇을 판정하는가

N18은 지금까지 나온 증거로 두 가지를 정한다. 하나는 각 선택 기능을 기본으로 켤지이고, 다른 하나는 프로젝트를 어디까지 내보낼지다. 작업리스트의 조건은 다음과 같다.

- 독립 평가, 원래 회귀, 비용, 대상 지원, 운영 결정을 근거로 판정한다.
- 합격 근거가 없으면 disabled 또는 보류를 유지한다.
- 실제 merge, push, 배포는 별도 권한으로만 한다.

## 4. 회귀 시험(HEAD `c85bac89`)

[요약](../../system/eval/b0-knowledge-system/refactoring-n18-release-verdict-2026-10-11/regression-summary.json)의 결과다.

- `go test -race ./...`: 시험 3,252개 통과, 16개 skip, **1개 실패**.
- `go vet`, gofmt: 문제 0건.
- Python script 시험: 164개 통과.
- 당시 실패한 `internal/graph/server` `TestHandleImpact_BadRequest`는 본문은 통과했지만, TempDir 정리 단계에서 "directory not empty"로 실패했다. 이 단계에서는 패키지를 바꾸지 않았다(마지막 변경 `849e127d`). 단독 재실행은 3/3 통과했다. 당시에는 간헐적인 시험 격리 결함으로 보고 머지 전 원인 확인을 권장했다. 아래 후속 수정에서 원인을 찾아 고쳤다.
- **2026-10-11 후속: 원인 수정(`396242f0`).** 원인은 `persist.OpenReadOnly`의 DSN이 `file:` URI가 아니어서 `mode=ro`·`immutable=1`이 무시된 것이었다. 그 결과 읽기 전용 handle이 실제로는 읽기·쓰기로 열렸고, 쓰기를 허용하고 `-wal`/`-shm`을 만들었다. 늦게 닫힌 연결이 TempDir 정리와 경쟁해 실패했다. 회귀 시험은 수정 전 RED, 수정 후 GREEN이다. 수정 후 전체 race는 3,257개 통과, 실패 0이다([기록](../../system/eval/b0-knowledge-system/refactoring-graph-readonly-fix-2026-10-11/findings.json)). 선택 기능 기본값과 공개 배포 보류 판정은 바뀌지 않았다.

## 5. N16 보류 결정

N16에서 남은 조건은 "공개키 fingerprint" 하나다. 사용자는 2026-10-10에 서명 키를 쓰지 않기로 했다. 당시 검토한 선택지는 두 가지였다.

1. **로컬 서명 키를 만들어 release commit과 binary SHA 목록에 서명한다.** 개인키는 이 Mac에만 두고 저장소에는 fingerprint만 기록한다. N16을 완료할 수 있다. 대신 키를 보관하고 교체하는 책임이 생긴다.
2. **미충족으로 둔다.** 이 경우 공개 배포 보류의 이유가 하나 더 남는다. 로컬 개인 운영에는 영향이 없다.

사용자는 2번을 선택했고 2026-10-12에 N16 보류를 다시 확인했다. N16은 완료 처리하지 않는다.

## 6. 승인과 후속 처리

1. 2026-10-11에 선택 기능 기본값 유지와 로컬 개인 운영 허용을 승인했다. 당시 `main` 머지와 공개 배포는 보류했다.
2. N16은 미충족으로 두기로 했고, 2026-10-12에 보류를 다시 확인했다.
3. 2026-10-12 별도 지시로 `main` 머지 보류를 해제하고 PR #98을 머지했다. 태그와 공개 배포는 계속 보류한다.

머지는 완료됐다. 태그와 공개 배포에는 별도 결정이 필요하다.

**남은 전체 1개:** N16 신뢰·권한(공개키 fingerprint, 사용자 결정으로 보류·미충족).
