# N18 기본값·출시 판정

2026-10-11 · **사용자 승인(초안대로), N18 완료**. N16은 사용자 결정으로 미충족 유지. 전체17/18, 남은1개(N16).

승인 기록: 2026-10-11 사용자가 2절·3절 판정을 "초안대로 승인"했고, N16은 "미충족으로 둠"을 골랐다. 이 승인은 merge·push·배포 권한을 주지 않는다.

## 1. 무엇을 판정하는가

N18은 지금까지 나온 증거로 두 가지를 정한다. 하나는 각 선택 기능을 기본으로 켤지이고, 다른 하나는 이 브랜치를 어디까지 내보낼지다. 작업리스트의 조건은 다음과 같다.

- 독립 평가, 원래 회귀, 비용, 대상 지원, 운영 결정을 근거로 판정한다.
- 합격 근거가 없으면 disabled 또는 보류를 유지한다.
- 실제 merge, push, 배포는 별도 권한으로만 한다.

## 5. N16 처리

N16에서 남은 조건은 "공개키 fingerprint" 하나다. 사용자는 2026-10-10에 서명 키를 쓰지 않기로 했다. 선택지는 두 가지다.

1. **로컬 서명 키를 만들어 release commit과 binary SHA 목록에 서명한다.** 개인키는 이 Mac에만 두고 저장소에는 fingerprint만 기록한다. N16을 완료할 수 있다. 대신 키를 보관하고 교체하는 책임이 생긴다.
2. **미충족으로 둔다.** 이 경우 공개 배포 보류의 이유가 하나 더 남는다. 로컬 개인 운영에는 영향이 없다.

## 6. 사용자에게 필요한 결정

1. 2절과 3절의 판정 초안(선택 기능 기본값 유지, 로컬 운영 허용, merge·공개 배포 보류)을 승인할지.
2. N16을 5절의 1과 2 중 어느 쪽으로 처리할지.

판정은 승인되었다. merge, push, 배포는 하지 않았고, 하려면 별도 권한이 필요하다.
